You'll write every component yourself — tokenizer, embeddings, attention, training loop, and inference engine — with every single line annotated to explain what it does and why it's there.

You don't need any machine learning experience. If you know basic Python, you have everything you need to start.

## Architecture highlights

This guide implements a **modern decoder-only Transformer** — not the 2019 GPT-2 style, but the techniques used by LLaMA 3, Mistral, and Qwen 2.5 in production today.

| Technique | Why it matters |
|---|---|
| **RoPE** | Relative position encoding without learned parameters |
| **RMSNorm** | ~15% faster than LayerNorm, equally effective |
| **SwiGLU** | Learns which information to pass or block at scale |
| **Pre-Norm** | Stable training at 100+ layers |
| **AdamW** | Better generalization than vanilla Adam |
| **Mixed precision** | 2× speed, half memory, same quality |

<Note>
  GPT-4 and Claude architectures are proprietary. This guide teaches the best publicly-confirmed architecture: what LLaMA 3, Mistral, and Qwen 2.5 actually use.
</Note>
