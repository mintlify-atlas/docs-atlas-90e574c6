This page walks you through getting the project running on your machine. You'll clone the repository, create an isolated Python environment, install the required libraries, and verify your setup before diving into the chapters. The whole process takes about five minutes on a machine with a stable internet connection.

## Prerequisites

You need Python 3.10 or later and basic familiarity with the terminal. No machine learning experience is required.

| Requirement | Details |
|---|---|
| **Python 3.10+** | Check with `python --version` or `python3 --version` |
| **pip** | Comes bundled with Python; check with `pip --version` |
| **~2 GB disk space** | For dependencies and the WikiText-103 training dataset |
| **GPU (optional)** | CUDA-capable NVIDIA GPU or Apple Silicon. CPU works but is much slower |

<Note>
  No ML experience needed. If you've written Python functions and classes before, you're ready. Every concept — tensors, gradients, attention — is introduced from scratch in the chapters.
</Note>

## Setup

<Steps>
  <Step title="Clone the repository">
    Clone the project and move into the directory:

    ```bash
    git clone https://github.com/raiyanyahya/how-to-train-your-gpt.git
    cd how-to-train-your-gpt
    ```
  </Step>

  <Step title="Create a virtual environment">
    A virtual environment keeps this project's dependencies isolated from everything else on your system — think of it as a clean, empty kitchen dedicated to this project.

    <Tabs>
      <Tab title="Mac / Linux">
        ```bash
        python -m venv gpt_env
        source gpt_env/bin/activate
        ```
      </Tab>
      <Tab title="Windows">
        ```bash
        python -m venv gpt_env
        gpt_env\Scripts\activate
        ```
      </Tab>
    </Tabs>

    Once activated, your terminal prompt will show `(gpt_env)`. To leave the environment later, run `deactivate`.
  </Step>

  <Step title="Install dependencies">
    Install all required libraries with a single command:

    ```bash
    pip install torch tiktoken datasets numpy matplotlib
    ```

    | Library | What it does |
    |---|---|
    | **torch** | Core PyTorch: tensors, GPU operations, automatic differentiation |
    | **tiktoken** | OpenAI's fast BPE tokenizer — the same one used by GPT-3.5/4 |
    | **datasets** | HuggingFace datasets; downloads and caches WikiText-103 automatically |
    | **numpy** | Fast CPU array operations for data manipulation |
    | **matplotlib** | Plots training loss curves so you can see if the model is learning |

    <Note>
      If you have an NVIDIA GPU, install the CUDA-enabled version of PyTorch for full GPU acceleration. See the [PyTorch installation page](https://pytorch.org/get-started/locally/) to pick the right command for your CUDA version.
    </Note>
  </Step>

  <Step title="Verify your setup">
    Run the verification snippet to confirm PyTorch is installed and check whether a GPU is available:

    ```python
    import torch
    print(f"PyTorch version: {torch.__version__}")
    print(f"CUDA available:  {torch.cuda.is_available()}")
    if torch.cuda.is_available():
        print(f"GPU:             {torch.cuda.get_device_name(0)}")
        print(f"GPU memory:      {torch.cuda.get_device_properties(0).total_memory / 1e9:.1f} GB")
    ```

    <CodeGroup>

    ```text With GPU
    PyTorch version: 2.1.0
    CUDA available:  True
    GPU:             NVIDIA GeForce RTX 3090
    GPU memory:      24.0 GB
    ```

    ```text CPU only
    PyTorch version: 2.1.0
    CUDA available:  False
    ```

    </CodeGroup>

    If you see `CUDA available: True`, you're set up for full-speed training. If you see `False`, training still works — just slower. Either way, continue to the next step.

    <Tip>
      On Apple Silicon (M1/M2/M3), PyTorch uses Metal Performance Shaders (MPS) rather than CUDA. You'll see `CUDA available: False`, but training on the GPU is still available via `torch.device("mps")` and is significantly faster than CPU.
    </Tip>
  </Step>

  <Step title="Start reading">
    Open Chapter 0 to begin:

    ```bash
    open chapters/00_overview.md
    ```

    On Linux or Windows, open the file with your preferred Markdown viewer or editor. The chapters are plain Markdown files — any text editor works.
  </Step>
</Steps>

## Complete quick-start commands

Here are all the commands in sequence for a clean setup:

```bash
# 1. Clone
git clone https://github.com/raiyanyahya/how-to-train-your-gpt.git
cd how-to-train-your-gpt

# 2. Create environment
python -m venv gpt_env
source gpt_env/bin/activate          # Mac/Linux
# gpt_env\Scripts\activate           # Windows

# 3. Install dependencies
pip install torch tiktoken datasets numpy matplotlib

# 4. Verify GPU (optional but recommended)
python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}')"

# 5. Start reading!
open chapters/00_overview.md
```

## Running the training script

Once you've worked through the chapters, copy the full script from Chapter 10 and run it:

```bash
python main.py
```

**Expected output (RTX 3090, ~2 hours):**

```text
GPT initialized with 124,439,808 parameters
Training starting!
Step    100/50,000 | Loss: 6.2345 | LR: 1.50e-05 | Toks/sec: 45,000
Step    200/50,000 | Loss: 5.1234 | LR: 3.00e-05 | Toks/sec: 45,200
...
Step 50,000/50,000 | Loss: 2.8901 | LR: 1.00e-05 | Toks/sec: 44,800
✅ Training complete! 112.3 min | Best loss: 2.8901
```

The loss should drop steadily from ~6.2 at the start toward ~2.9 by step 50,000. A flat or rising loss after the first few hundred steps usually means a learning rate issue — Chapter 8 covers how to diagnose and fix this.

## Tiny vs. small model configs

Chapter 10 provides two configurations you can switch between depending on your hardware.

| Config | Layers | Dimensions | Parameters | Hardware | Speed |
|---|---|---|---|---|---|
| **Tiny** | 4 | 256 | ~10M | CPU | Hours |
| **Small** | 12 | 768 | 124M | GPU (12+ GB VRAM) | ~2 hours |

<Warning>
  Training the small (124M) model on CPU only is possible but will take 10–50× longer than on a GPU — plan for multiple days rather than hours. Use the tiny config for CPU-only machines.
</Warning>

Your hardware determines how long training takes. Use this table as a guide:

| Hardware | Model you can train | Approximate time |
|---|---|---|
| CPU only | Tiny (4 layers, 256 dims) | Hours |
| Apple M1/M2/M3 | Small (12 layers, 768 dims) | Hours |
| RTX 3060/4060 (12 GB) | GPT-2 small (124M params) | Few hours |
| RTX 3090/4090 (24 GB) | GPT-2 medium (350M params) | Few hours |
| A100 (80 GB) | GPT-2 large (774M params) | Hours |
