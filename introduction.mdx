**How to Train Your GPT** is a 12-chapter, 3,671-line interactive textbook that teaches you to build a complete large language model from absolute scratch. You'll write every component yourself — tokenizer, embeddings, attention mechanism, training loop, and inference engine — with every single line annotated to explain what it does and why it's there. By the end, you'll have built the same family of architecture that powers ChatGPT, Claude, LLaMA, and Mistral.

## What is a GPT?

Imagine you have a friend who has read **every book in the library**. You start a sentence:

> *"The cat sat on the..."*

Your friend, having read so many books, guesses the next word: **"mat"**.

That's all a GPT is: a machine that reads enormous amounts of text and learns to guess the next word. Everything else — the billions of parameters, the attention heads, the training runs — is engineering built in service of that single idea.

| Concept | What it means |
|---|---|
| **GPT** | A very smart "next-word guesser" |
| **Training** | Reading millions of books to learn patterns |
| **Text generation** | Playing "finish my sentence" forever |
| **Parameters** | The stored memory of all patterns learned |
| **Attention** | Knowing which words matter most for each prediction |

<Note>
  GPT-4 and Claude architectures are proprietary and undisclosed. This guide teaches the best publicly-confirmed architecture: what LLaMA 3, Mistral, and Qwen 2.5 actually use.
</Note>

## Architecture overview

This guide implements a **modern decoder-only Transformer** — not the 2019 GPT-2 style, but the techniques used by LLaMA 3, Mistral, and Qwen 2.5 in production today.

| Technique | Source model | Why it matters |
|---|---|---|
| **RoPE** | LLaMA, Mistral, Qwen | Relative position encoding without learned parameters |
| **RMSNorm** | LLaMA, Mistral, Gemma | ~15% faster than LayerNorm, equally effective |
| **SwiGLU** | PaLM, LLaMA, Gemini | Learns which information to pass or block |
| **Pre-norm** | GPT-3, all modern | Stable training at 100+ layers |
| **AdamW** | GPT-3+ | Better generalization than vanilla Adam |
| **BPE** | GPT-2/3/4 | Handles any text, including unseen words and emoji |
| **Weight tying** | GPT-2/3 | Saves ~30% parameters, improves training signal |
| **Mixed precision** | All production LLMs | 2× speed, half memory, same quality |

## How to read this guide

Every chapter follows the same four-step structure so you always know where you are.

<Steps>
  <Step title="Analogy">
    A plain-English, 5-year-old-level explanation to build intuition before any math. If you ever feel lost in the code, return here first.
  </Step>
  <Step title="Worked example">
    Real numbers traced through the computation so you see exactly what happens at each step.
  </Step>
  <Step title="Annotated code">
    Every line of Python includes a `WHAT` comment and a `WHY` comment — read top-to-bottom like a story.
  </Step>
  <Step title="Diagram">
    A Mermaid flowchart or ASCII visualization showing data flowing through the component.
  </Step>
</Steps>

<Tip>
  Lost in the code? Jump back to the analogy. Confused by the math? Skip straight to the worked example.
</Tip>
