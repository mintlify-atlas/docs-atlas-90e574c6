Everything built across the previous chapters — the tokenizer, the GPT model, the training pipeline, and the inference code — converges in a single `main.py` file. You copy the file into your project, uncomment the model config you want, and run it. This page shows both available model configurations, the expected output format you will see during training, how to run on CPU versus GPU, and the recommended file organization for splitting the script into separate modules.

## How to use this script

Copy `main.py` into your project directory alongside the supporting modules. The script imports from those modules at the top. When you run it, it will:

1. Set up the device (GPU → Apple Silicon → CPU, in that order)
2. Initialize the tokenizer
3. Download and tokenize WikiText-103
4. Create the model
5. Train, printing loss and tokens-per-second every 100 steps
6. Save a loss curve PNG
7. Generate sample text from three prompts

## Model configurations

Choose between the TINY config for a quick smoke test and the SMALL config for a full training run.

<Tabs>
  <Tab title="Tiny model">
    Use the TINY config to verify your setup works end-to-end before committing to a long training run. It trains in roughly 5 minutes on a GPU.

    ```python
    # TINY MODEL (for quick testing, ~5 min on GPU)
    config = GPTConfig(
        vocab_size=50257,
        d_model=256,          # Small embedding
        num_heads=4,          # Few heads
        num_layers=4,         # Few layers
        max_seq_len=256,      # Short context
        batch_size=4,         # Tiny batch
        grad_accum_steps=2,   # Effective batch = 8
        max_steps=5000,       # Quick training
    )
    ```
  </Tab>
  <Tab title="Small model">
    The SMALL config matches GPT-2 small in dimension and depth. This is the recommended config for real training — you will see coherent text generation after roughly 50,000 steps.

    ```python
    # SMALL MODEL (GPT-2 small scale — recommended!)
    config = GPTConfig(
        vocab_size=50257,
        d_model=768,          # GPT-2 small dimension
        num_heads=12,         # 12 heads x 64 dims
        num_layers=12,        # GPT-2 small depth
        max_seq_len=1024,     # 1024 tokens context
        max_steps=50000,      # Decent results
        batch_size=4,
        grad_accum_steps=8,   # Effective batch = 32
    )
    ```

    <Warning>
    The SMALL config requires approximately 6–8 GB of GPU VRAM with `batch_size=4` and bfloat16 enabled. If you run out of memory, reduce `batch_size` to 2 and increase `grad_accum_steps` to 16 to keep the effective batch size at 32.
    </Warning>
  </Tab>
</Tabs>

## Running the script

<CodeGroup>

```bash GPU (recommended)
python main.py
```

```bash GPU — monitor usage
# In a second terminal while training runs:
watch -n 1 nvidia-smi
```

```bash CPU
python main.py
```

</CodeGroup>

<Note>
CPU training is 10–50× slower than GPU training. The TINY config takes roughly 5 minutes on a modern GPU; on CPU that becomes 1–4 hours. The SMALL config is not practical to train on CPU. If you do not have a GPU, consider Google Colab (free T4) or Kaggle Notebooks (free P100).
</Note>

## File organization

As the codebase grows, split `main.py` into separate modules. The imports at the top of `main.py` reflect this organization:

```
project/
├── main.py          # Entry point — calls everything below
├── tokenizer.py     # SimpleTokenizer, TokenizerConfig
├── model.py         # GPT, GPTConfig, TransformerBlock, MultiHeadAttention,
│                    # RMSNorm, SwiGLU, RotaryPositionalEmbedding, create_causal_mask
├── training.py      # TextDataset, load_training_data, CosineWarmupScheduler,
│                    # create_optimizer, train, plot_loss
└── inference.py     # load_checkpoint, generate_text
```

Each module is independently importable and testable. Start with everything in one file if you prefer, then extract modules when the file becomes unwieldy.

## The complete `main()` function

```python
# ===== main.py =====
# WHAT: The complete script to train a GPT from scratch.
# WHY: Everything we've built comes together here.
#      Run this file and watch your GPT learn!

import torch

# Import all our modules (assuming they're in the same directory)
# In practice, you'd organize these into separate .py files:
#   tokenizer.py -> SimpleTokenizer, TokenizerConfig
#   model.py     -> GPT, GPTConfig, TransformerBlock, MultiHeadAttention,
#                   RMSNorm, SwiGLU, RotaryPositionalEmbedding, create_causal_mask
#   training.py  -> TextDataset, load_training_data, CosineWarmupScheduler,
#                   create_optimizer, train, plot_loss
#   inference.py -> load_checkpoint, generate_text


def main():
    """
    WHAT: Main entry point.
    WHY: Setup -> data -> model -> train -> generate
    """

    # ===== 1. CONFIGURATION =====
    print("How to Train Your GPT — Starting up!\n")

    # WHAT: Choose model size
    # WHY: Tiny for testing, small for real training

    # TINY MODEL (for quick testing, ~5 min on GPU)
    config = GPTConfig(
        vocab_size=50257,
        d_model=256,          # Small embedding
        num_heads=4,          # Few heads
        num_layers=4,         # Few layers
        max_seq_len=256,      # Short context
        batch_size=4,         # Tiny batch
        grad_accum_steps=2,   # Effective batch = 8
        max_steps=5000,       # Quick training
    )

    # SMALL MODEL (GPT-2 small scale — recommended!)
    # config = GPTConfig(
    #     vocab_size=50257,
    #     d_model=768,          # GPT-2 small dimension
    #     num_heads=12,         # 12 heads x 64 dims
    #     num_layers=12,        # GPT-2 small depth
    #     max_seq_len=1024,     # 1024 tokens context
    #     max_steps=50000,      # Decent results
    #     batch_size=4,
    #     grad_accum_steps=8,   # Effective batch = 32
    # )

    # ===== 2. DEVICE SETUP =====
    if torch.cuda.is_available():
        device = torch.device("cuda")
        print(f"GPU: {torch.cuda.get_device_name(0)}")
        print(f"Memory: {torch.cuda.get_device_properties(0).total_mem / 1e9:.1f} GB")
    elif hasattr(torch.backends, "mps") and torch.backends.mps.is_available():
        device = torch.device("mps")
        print("Using Apple Silicon (MPS)")
    else:
        device = torch.device("cpu")
        print("Warning: Using CPU — training will be very slow!")

    # ===== 3. TOKENIZER =====
    tokenizer = SimpleTokenizer()

    # ===== 4. LOAD DATA =====
    print("\nLoading training data...")
    # WHAT: Start with 5000 documents for quick testing
    # WHY: Increase to None for full dataset once everything works
    texts = load_training_data(max_samples=5000)
    train_dataset = TextDataset(texts, tokenizer, max_seq_len=config.max_seq_len)

    # ===== 5. CREATE MODEL =====
    print("\nCreating model...")
    model = GPT(config)
    print(f"   Total parameters: {model.get_num_params():,}")
    trainable = sum(
        p.numel() for p in model.parameters() if p.requires_grad
    )
    print(f"   Trainable: {trainable:,}")

    # ===== 6. TRAIN =====
    print("\n" + "="*60)
    print("STARTING TRAINING")
    print("="*60)
    loss_history = train(model, train_dataset, config, device)

    # ===== 7. PLOT LOSS =====
    plot_loss(loss_history)

    # ===== 8. GENERATE TEXT =====
    print("\n" + "="*60)
    print("GENERATING SAMPLE TEXT")
    print("="*60 + "\n")

    prompts = [
        "The history of artificial intelligence",
        "In the beginning, the universe",
        "The most important scientific discovery",
    ]

    for prompt in prompts:
        generated = generate_text(
            model=model,
            tokenizer=tokenizer,
            prompt=prompt,
            max_new_tokens=80,
            temperature=0.8,
            top_k=50,
            device=device,
        )
        print(f"Prompt: {prompt}")
        print(f"Output: {generated}")
        print("-" * 60)
        print()

    print("Done! Your GPT is trained and ready.")


if __name__ == "__main__":
    main()
```
